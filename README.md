# 连连看网页小游戏

一个可爱风格的连连看网页小游戏，使用HTML、CSS和JavaScript实现。

![连连看游戏截图](https://via.placeholder.com/600x400?text=连连看游戏截图)

## 如何运行

1. 下载或克隆此仓库到本地
2. 直接在浏览器中打开`index.html`文件

## 游戏规则

1. 点击"开始游戏"按钮开始游戏
2. 在游戏板上找到两个相同的图案，依次点击它们
3. 如果两个图案可以通过不超过2个拐点的路径连接，它们将被消除
4. 在规定时间内消除所有方块获胜
5. 每消除一对方块获得10分

## 游戏特点

- 8x8的游戏板，共64个方块，32对水果图案
- 60秒倒计时
- 显示连接路径
- 响应式设计，适配不同设备
- 多种动画效果：
  - 方块消除动画
  - 分数增加动画
  - 连接路径动画
  - 胜利时五彩纸屑特效

## 游戏道具

游戏内置三种道具，增加游戏的趣味性和策略性：

1. **提示道具 (💡)** - 高亮显示一对可连接的方块，每局游戏3次
2. **时间道具 (⏰)** - 增加10秒游戏时间，每局游戏2次
3. **洗牌道具 (🔄)** - 重新排列剩余方块，每局游戏1次

当没有可连接的方块时，系统会自动使用洗牌道具（如果有）。

## 技术细节

- 纯原生JavaScript，无需任何框架
- 使用CSS Grid布局游戏板
- 路径查找算法支持0、1和2个拐点的连接
- 响应式设计，适配移动端和桌面端
- 动态生成的动画效果
- 使用Google Font "ZCOOL KuaiLe" 增强可爱风格
